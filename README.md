# Miami Free Roam — Unity Android

Проект мобильной 3D-игры для прогулки по статичному городу от третьего лица.

## Сборка APK
1. Добавьте в GitHub Secrets репозитория секрет `UNITY_LICENSE` с лицензией Unity Personal/Pro в формате, который поддерживает GameCI.
2. Откройте Actions → Build Android APK → Run workflow.
3. После успешной сборки скачайте артефакт `MiamiFreeRoam-Android-APK`.

Пока в репозитории нет исходной 3D-модели города, проект создаёт демонстрационный квартал Майами из объектов Unity. Чтобы использовать исходный детализированный город, поместите OBJ и MTL в `Assets/Miami/Models/` с именами:
- `city-real-place-25-77400-80-19400.obj`
- `city-real-place-25-77400-80-19400.mtl`

При импорте OBJ автоматически создаётся сцена с персонажем. Управление: левый джойстик — движение, правая часть экрана — камера, кнопки RUN и JUMP. На ПК в редакторе — WASD и мышь.

## Текущий статус
Это исходный Unity-проект и конфигурация CI. APK считается готовым только после успешного выполнения GitHub Actions.
